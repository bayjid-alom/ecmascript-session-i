## 🆚 var vs let vs const

| Feature | `var` | `let` | `const` |
|---|---|---|---|
| Scope | Function Scope | Block Scope | Block Scope |
| Reassign | ✅ Yes | ✅ Yes | ❌ No |
| Redeclare | ✅ Yes | ❌ No | ❌ No |
| Hoisting | ✅ Yes | ✅ Yes | ✅ Yes |
| Temporal Dead Zone (TDZ) | ❌ No | ✅ Yes | ✅ Yes |
| Must initialize | ❌ No | ❌ No | ✅ Yes |
| Introduced | JavaScript 1.0 | ES6 | ES6 |
